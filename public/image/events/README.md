# Event images

Event photos and assets used in comunicati stampa (press) pages.

## KEY ENERGY 2026 — Afore Italia

**Folder:** this folder (`public/image/events/`).

**Naming:**  
`keyenergy2026_afore_italia_01.jpg`, `keyenergy2026_afore_italia_02.jpg`, … `keyenergy2026_afore_italia_20.jpg`  
(use two digits: 01, 02, … 10, 11, … 20).

- Put as many photos as you have; the detail page is currently wired to the\n+  `KEYENERGY2026_AFORE_ITALIA_PHOTOS` array in\n+  `src/app/[lang]/comunicati-stampa/[slug]/page.tsx`.\n+- If you have more than 20, add more paths in that array (e.g. `keyenergy2026_afore_italia_21.jpg`, …).  \n+- If you have fewer than 20, remove the extra entries from that array so no broken images appear.
